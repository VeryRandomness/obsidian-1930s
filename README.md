# 1930s

A greyscale Obsidian theme with muted callout colours.

## Install
- **Manually:** copy `theme.css` and `manifest.json` into `<vault>/.obsidian/themes/1930s/`, then pick **1930s** under Settings → Appearance → Themes.
- **Auto-updating:** add this repo's link in the Theme Auto-Update plugin's settings.

Supports the [Style Settings](https://github.com/obsidian-community/obsidian-style-settings) plugin for note width and corner radius.
